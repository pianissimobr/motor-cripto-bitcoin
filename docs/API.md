# API do Motor Cripto

O manual de quem integra e de quem opera é o livro em HTML.

- No ar: `http://localhost:4578/docs/` (a mesma origem da API; em produção, `PUBLIC_BASE_URL/docs/`).
- No repositório: [web/docs/index.html](../web/docs/index.html).
- Índice de rotas, dentro do livro: [web/docs/18-referencia.html](../web/docs/18-referencia.html).

Cada capítulo traz o objetivo, o método, o contrato HTTP e o que a API recusa. Este arquivo não repete os corpos JSON, para não haver dois manuais.

O mapa do código, para quem vai abrir os arquivos, continua em [guia.md](guia.md).
