Criar a cobrança

POST /v1/payment-intents reserva um endereço, cria a invoice e devolve o que a loja precisa mostrar. O corpo é assinado como está.

ObjetivoCriar, reler e cancelar uma cobrança sem inventar campo.

Corpo

{
  "external_id": "pedido-123",
  "amount_sats": "10000",
  "description": "Pedido 123",
  "expires_in_seconds": 600,
  "metadata": { "order_id": "123" }
}

external_id e amount_sats são obrigatórios. description tem no máximo 200 caracteres e vira o label da URI. expires_in_seconds é opcional. metadata é um objeto livre, guardado com a cobrança e não devolvido no webhook.

Resposta

Cobrança nova responde 201. Reuso do mesmo external_id e do mesmo valor responde 200.

{
  "id": "uuid",
  "external_id": "pedido-123",
  "status": "pendente",
  "amount_sats": "10000",
  "description": "Pedido 123",
  "expires_at": "2026-10-29T12:10:00.000Z",
  "grace_until": "2026-10-30T12:10:00.000Z",
  "paid_at": null,
  "paid_rail": null,
  "paid_amount_sats": null,
  "overpaid_sats": null,
  "lightning": {
    "invoice": "lnbc...",
    "payment_hash": "...",
    "expires_at": "2026-10-29T12:10:00.000Z"
  },
  "onchain": {
    "address": "bc1q...",
    "amount_btc": "0.00010000",
    "bip21": "bitcoin:bc1q...?amount=0.00010000&label=Pedido%20123&lightning=lnbc..."
  },
  "payment_uri": "bitcoin:bc1q...?amount=0.00010000&lightning=lnbc...",
  "qr_svg": "<svg ...>",
  "created_at": "2026-10-29T12:00:00.000Z",
  "updated_at": "2026-10-29T12:00:00.000Z"
}

O mesmo external_id e o mesmo valor devolvem a cobrança já pendente com 200. Outro valor no mesmo id devolve 409. Se a criação ainda está em criando, a resposta é 409 pedindo para tentar de novo, sem devolver uma cobrança sem invoice. Se a invoice falhou, o status fica falha_criacao e esse external_id não serve para uma nova tentativa.

Ler e cancelar

  • GET /v1/payment-intents/:id
  • GET /v1/payment-intents?external_id=pedido-123
  • POST /v1/payment-intents/:id/cancel sem corpo. Só em pendente. Responde a cobrança já cancelado.

O GET com query também é assinado. O PATH da string canônica é /v1/payment-intents, sem a query. O corpo assinado é vazio.

Uma loja não lê a cobrança de outra. Id desconhecido ou de outro cliente é 404.
