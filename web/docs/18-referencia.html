Referência de rotas

Uma linha por rota do serviço Bitcoin. Os corpos completos estão no capítulo, não aqui. A base local é http://localhost:4580.

ObjetivoAchar a rota certa sem reler o livro, e saber para onde voltar quando o campo não bastar.

O que este serviço não tem

Não há /v1/links, /p/:token, perfil Ramp, carteira allowlisted por cliente, centavos de real nem cotação. Essas rotas pertenciam ao motor Polygon que ainda está em src/. Chamar qualquer uma delas nesta API devolve 404.
