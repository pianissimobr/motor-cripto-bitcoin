O livro da API

Este livro ensina o que o Motor Cripto faz, em que ordem ele faz, e qual chamada HTTP corresponde a cada passo. Ele é para a pessoa que integra a loja e para quem opera o admin.

ObjetivoSaber qual parte abrir conforme a pergunta: o que o motor é, como um pagamento anda, qual JSON enviar, ou o que fazer quando algo falha.

O motor não é a loja, não é a Ramp e não é uma carteira de celular. A loja quer receber stablecoin numa carteira que ela mesma cadastrou. Quem paga está acostumado a reais. A Ramp faz essa ponte, mas não avisa a loja quando o valor cai, a menos que exista uma conta empresarial. O motor observa a blockchain e avisa a loja.

Leia na ordem se esta é a primeira vez. Se você já sabe o que quer chamar, a referência de rotas aponta o capítulo certo. O mapa do código, para quem vai abrir os arquivos, continua em docs/guia.md.

Os números que voltam em todo o livro são estes: R$ 150,00 são 15000 centavos. O perfil de exemplo cobra 180000 unidades mínimas de USDC por real, então o esperado é 27 USDC, escritos como "27000000". A tolerância padrão é 1%. A página dura 60 minutos. A leitura on-chain continua por 1 dia. Datas saem em UTC.
