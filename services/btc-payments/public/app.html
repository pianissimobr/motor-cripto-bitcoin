Perguntas frequentes

    

      O motor guarda o meu dinheiro?
      
Não. Ele só cria o caminho (QR/invoice) e confirma a chegada. A liquidação (USDC) vai para a carteira que você cadastrar.

    

    

      Como recebo o valor das vendas?
      
Cadastre uma carteira usdc_settlement (endereço 0x na Base) em "Carteiras". O valor recebido é convertido e enviado para ela.

    

    

      Onde estão a API key e os secrets?
      
Eles aparecem uma única vez, na criação da loja. Depois você só enxerga o prefixo. Perdeu? Use "Rotacionar API key".

    

    

      O que é o xpub de depósito?
      
É a sua chave pública de conta BIP84 (m/84'/0'/0'). Deriva os endereços de recebimento sem poder gastar. Nunca cole xprv/seed.

    

    

      Lightning ou on-chain, qual aparece no QR?
      
O QR mostrado é BIP21 e já embute a invoice Lightning quando existe. O cliente pode pagar pelo canal mais rápido; o motor confirma qualquer um dos dois.

    

    

      Como sei que um pagamento foi confirmado?
      
Pelo webhook (evento payment_intent.paid) ou consultando GET /v1/payment-intents/:id. A página /pay/:id/status também atualiza sozinha.

    

    

      Por que minha chamada retorna 401?
      
As causas mais comuns: relógio fora de ±300 s (ative NTP), nonce reutilizado, assinatura mal montada (assine o corpo cru) ou caminho com query string na string canônica.

    

    

      Para que serve o external_id?
      
É a chave de idempotência. Repetir a mesma cobrança com o mesmo external_id devolve a mesma cobrança, sem criar outra. Com outro valor, dá 409.

    

    

      Posso receber via PIX?
      
Se o PIX estiver habilitado na sua conta, sim: POST /v1/pix-charges. O CPF/CNPJ do pagador é exigido pela provedora.

    

    

      Como funcionam as assinaturas?
      
Você define valor e ciclo. A cada ciclo o motor gera uma nova cobrança e avisa pelo webhook. Não há débito automático — o cliente aprova cada ciclo.

    

    

      Meu webhook não chegou. E agora?
      
Confira se a webhook_url está configurada e retorna 2xx rápido. O motor re-tenta com backoff; falhas finais são visíveis só pelo operador/replay.

    

    

      Onde vejo meus relatórios?
      
Neste painel (indicadores acima) e em /v1/portal/merchants/:id/reports/* — volume, por rail e série temporal.
